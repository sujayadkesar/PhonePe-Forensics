📂 Where to find the evidence folder

A full-filesystem / rooted Android extraction stores everything under one private app-data directory. Point the analyser at:

com.phonepe.app
The PhonePe package data dir. Contains databases/ (Room SQLite — phonepe_core holds transactions, chat, contacts, ledger), shared_prefs/, files/ and app_webview/.
Typical location: data/data/com.phonepe.app/ (or /data/user/0/com.phonepe.app/)

Tip: Select the folder literally named com.phonepe.app (the one that contains a databases sub-folder). 3 databases are SQLCipher-encrypted and are recorded as present-but-not-decryptable; everything else is parsed.
