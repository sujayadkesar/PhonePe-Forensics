How to read this page

Every row below is a reconstruction, not a row the database still holds — the live tables are unchanged and these are excluded from them. A record is listed only when it is absent from the live table, so a stale copy of a row that still exists is never reported as a deletion.

Confidence is high when the record's extent was confirmed structurally — an intact header, or an end that lines up exactly with the next freed cell — and medium when the field boundaries had to be inferred and could be off by a byte. Partial means SQLite's freeblock header overwrote the record's first serial type; the value is recovered from the surviving bytes but its type is gone.

Pool is where the bytes came from: freelist (a released page), freeblock (a released cell inside a live page), page-slack (a page's unallocated middle), pre-wal-image / wal-superseded (a page version the WAL replaced), journal (a rollback pre-image).
