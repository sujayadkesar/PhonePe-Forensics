📂 Where to find the evidence folders

An iOS full-filesystem extraction (e.g. via Cellebrite / GrayKey / checkm8 / AFC2) produces one directory per app container. The three PhonePe containers are always named:

AppDomain-com.phonepe.PhonePeApp
Main app sandbox — SQLite transaction database, Preferences, Cookies, WebKit cache
Typical location: private/var/mobile/Containers/Data/Application/<UUID>/
AppDomainGroup-group.com.phonepe.PhonePeApp
Shared group container — Chat (Burble), Contacts (SamparkV2), P2P events
Typical location: private/var/mobile/Containers/Shared/AppGroup/<UUID>/
AppDomainGroup-group.com.phonepe.shared
Cross-app shared session — auth tokens, device fingerprint, config state
Typical location: private/var/mobile/Containers/Shared/AppGroup/<UUID>/

Tip: In Cellebrite PA the containers appear under iOS > Databases > App Databases. In a raw FS dump they appear as top-level directories in the extraction root — just point "Single root folder" at that directory.
